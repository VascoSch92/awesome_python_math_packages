# Contribution Guidelines

Please note that this project is released with a [Contributor Code of Conduct](https://github.com/sindresorhus/awesome/blob/main/code-of-conduct.md). By participating in this project you agree to abide by its terms.

## Adding a package

- The package must be written in (or have first-class bindings for) Python and deal with mathematics.
- It must be actively maintained: not archived, with commits in the last two years.
- Check that it is not already in the list.
- Add one package per line, in the most fitting section, in alphabetical order (case-insensitive).
- Use the format `- [Name](https://github.com/owner/repo) - Description.`
  - Link to the source repository.
  - Keep the description short, start it with a capital letter and end it with a period.
  - Avoid marketing words such as "the best" or "blazing fast".
- New sections are welcome when at least three packages fit them.

## Updating the list

- Fix broken or redirected links, and remove packages that are archived or abandoned.
- Open a pull request with a short title describing the change, for example `Add PySINDy`.

Thank you for your suggestions!
