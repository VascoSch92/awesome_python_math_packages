# Unmaintained Packages

Packages moved out of the main list because their repository is archived, no longer available, or has had no activity in the last two years. If one of them becomes active again, open a pull request to move it back.

## Algebra

- [abstract_algebra](https://github.com/alreich/abstract_algebra) - Abstract Algebra: An implementation of Finite Algebras: Groups, Rings, Fields, Vector Spaces, Modules, Monoids, Semigroups, and Magmas.
- [Hypercomplex](https://github.com/discretegames/hypercomplex) - A Python library for working with arbitrary-dimension hypercomplex numbers following the Cayley-Dickson construction of algebras.
- [jaxga](https://github.com/RobinKa/jaxga) - Geometric Algebra package for JAX.
- [PyFinite](https://github.com/emin63/pyfinite) - Finite field math in Python including generic matrix operations and Reed-Solomon error correcting codes.
- [PyOctonion](https://github.com/charithsiu/pyoctonion) - Python Library for octonion.

## Analysis

- [torchsde](https://github.com/google-research/torchsde) - Differentiable SDE solvers with GPU support and efficient sensitivity analysis.

## Animations and Images

- [Blender_ParadoxToolkit](https://github.com/matgarate/Blender_ParadoxToolkit/tree/master) - A toolkit to create 3D optical illusion in Blender.
- [Fourier-and-Images](https://github.com/thinking-tower/Fourier-and-Images) - Fourier and Images.
- [Hyperbolic](https://github.com/cduck/hyperbolic) - A Python 3 library for constructing and drawing hyperbolic geometry.
- [MathArtist](https://github.com/qiray/MathArtist) - Tool for generating pictures using mathematical formulas.
- [Maige](https://github.com/chahak13/maige) - Python package to generate math based images.
- [visma-VISual MAth](https://github.com/aerospaceresearch/visma) - An equation solver and visualizer.

## General Mathematics

- [libMath](https://github.com/4pz/libmaths) - A Python library created to assist programmers with complex mathematical functions.
- [SimPa](https://github.com/jnmclarty/sympa) - Symbolic math for Pandas.

## Geometry

- [meshio](https://github.com/nschloe/meshio) - Input/output for many mesh formats.
- [pygmsh](https://github.com/nschloe/pygmsh) - A high-level abstraction for the mesh generator Gmsh in Python.

## Group Theory

- [abelian](https://github.com/tommyod/abelian) - Computations on locally compact Abelian groups.
- [abeliantensors](https://github.com/mhauru/abeliantensors) - A library for Abelian symmetry preserving tensors in Python 3.
- [liepy](https://github.com/gutfeeling/liepy) - Computes representation matrices for Lie groups.

## Learning Math

- [FUNMATH](https://github.com/mingrammer/funmath/tree/master) - Implementations of mathematical functions, formulas and concepts.

## Linear Algebra

- [block](https://github.com/bamos/block) - An intelligent block matrix library for NumPy, PyTorch, and beyond.
- [hermite-function](https://github.com/goessl/hermite-function) - A Hermite function series module.
- [multipoly](https://github.com/goessl/multipoly) - A multivariate polynomial module.
- [pygraphblas](https://github.com/Graphegon/pygraphblas) - A Python wrapper around the GraphBLAS API for sparse linear algebra on graphs.
- [vg](https://github.com/lace/vg) - Vector-geometry and linear-algebra toolbelt for 3D points and vectors.
- [xitorch](https://github.com/xitorch/xitorch) - Differentiable scientific computing library (linear algebra, optimization, integration) for PyTorch.

## Number Theory

- [AlgNuTh](https://github.com/louisabraham/algnuth) - Algebraic Number Theory package.
- [Number-Theory-Python](https://github.com/Robert-Campbell-256/Number-Theory-Python) - Python code implementing various number theory, elliptic curve and finite field computations.
- [primePy](https://github.com/janaindrajit/primePy) - This module cal quickly find prime factors with multiplicity of a given number. This module also has several other prime factor functions.
- [sequentium](https://github.com/VascoSch92/sequentium) - A user-friendly package that implements various well-known sequences.

## Optimization

- [PySwarms](https://github.com/ljvmiranda921/pyswarms) - A research toolkit for particle swarm optimization (PSO) in Python.

## Probability and Statistics

- [WagerBrain](https://github.com/sedemmler/WagerBrain) - A package containing the essential math required for sports betting and gambling.
